# Contributing Guidelines

## Code Standards

### Comments and Documentation
- **All code comments must be written in English**
- Use clear, concise language
- Document complex logic and algorithms
- Include function/method documentation for public APIs

### Code Style
- Follow C++17/23 standards if possible
- Use meaningful variable and function names
- Keep functions focused and single-purpose
- Respect SOLID principles if possible.
- Use modern C++ features whenever possible (smart pointers, range-based for loops, etc.)

### Git Commit Messages
- Write commit messages in English
